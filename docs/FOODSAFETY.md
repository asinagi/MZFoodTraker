# 식품안전나라 공공데이터 연동 (1단계)

유행 음식의 **공급 쪽 정보**를 식약처 공공데이터로 보강하는 독립 모듈입니다.
기존 수집·추적·Oracle·B8 코드는 수정하지 않았고, 기존 DB에도 쓰지 않습니다.

| 파일 | 역할 |
| --- | --- |
| `food_trends/foodsafety.py` | 조회·분석·캐시·CLI |
| `tests/test_foodsafety.py` | 오프라인 테스트 13개 (2026-11-09 실제 응답 일부를 고정 데이터로 사용) |

## 사용하는 공공데이터

| 서비스ID | 이름 | 쓰는 항목 |
| --- | --- | --- |
| `I1250` | 식품(첨가물)품목제조보고 | 제품명, 제조사, 식품유형, 허가(신고)일, 용도 |
| `C002` | 식품(첨가물)품목제조보고(원재료) | 제품별 원재료 목록 |

두 데이터는 품목보고번호(`PRDLST_REPORT_NO`)로 연결합니다.

## 설정

`.env`에 인증키를 추가합니다 (`.env`는 git 제외 대상이라 커밋되지 않습니다).

```
FOODSAFETY_I1250_KEY=품목제조보고_인증키
FOODSAFETY_C002_KEY=원재료_인증키
# 키가 하나뿐이면 대신 FOODSAFETY_API_KEY= 하나만 넣어도 됩니다.
```

## 실행

```bash
# 요약 출력 (공급 추이, 핵심 원재료, 최근 제품)
python -m food_trends.foodsafety 두쫀쿠 --alias 두바이쫀득쿠키

# 전체 JSON
python -m food_trends.foodsafety 약과 --json

# 캐시 무시하고 다시 조회
python -m food_trends.foodsafety 약과 --refresh

# 음식 분석 + 핵심 재료 상위 3개의 공급업체까지
python -m food_trends.foodsafety 두쫀쿠 --alias 두바이쫀득쿠키 --suppliers 3

# 재료 하나의 제품·공급업체만 조회
python -m food_trends.foodsafety 피스타치오 --ingredient
python -m food_trends.foodsafety 카다이프 --ingredient
```

- 결과는 `data/foodsafety/*.json`에 캐시되고, 같은 조회는 API를 다시 부르지 않습니다.
- 1회 요청 1,000건, 검색어당 기본 최대 5,000건(`--max-rows`로 조정).

## 결과 항목

| 항목 | 의미 |
| --- | --- |
| `counts.products` | 별칭 검색 결과를 품목보고번호로 중복 제거한 제품 수 |
| `counts.core` / `derived` | 음식명 뒤에 맛·색·포장 표현만 오면 `core`(그 음식 자체·변형, 예: `두바이쫀득쿠키 말차`, `6개입`), 케이크·스프레드·키트·`~맛`·`~향`·`~스타일`이 오면 `derived`(그 음식 맛의 다른 제품, 예: `두쫀쿠케익`, `하루단백바 두쫀쿠맛`). **이름 규칙 기반 추정**이며 2026-11-09 두쫀쿠 108건 기준으로 맞춤. |
| `monthly_permits` | 월별 허가(신고) 건수 = **공급 추이**. SNS 관심도 추이와 겹쳐 보면 진입 시점 판단 근거가 됩니다. |
| `top_ingredients` | core 제품 기준 원재료 빈도. `share`는 그 재료를 쓴 제품 비율이며 **함량이 아닙니다**. |
| `products` | 제품 목록(최신순): 제품명, 제조사, 식품유형, 허가일, 원재료 |

## 재료별 제품·공급업체 (`--ingredient`, `--suppliers N`)

재료명으로 품목제조보고(I1250)를 검색해 **재료로 쓰는 제품**과 그 **제조사(공급업체)**를 정리합니다.

- 재료용 판단(추정, 2026-11-10 피스타치오 실제 결과로 조정):
  - 제외: 쿠키·케이크·카스텔라·샌드·파운드·단백·프로틴 등 완제품 표현, `피스타치오향`·`피스타치오맛`(향료·맛 변형),
    완제품 식품유형(빵류·과자·떡류·캔디류 등)인데 페이스트·스프레드·분말 같은 확실한 재료 형태가 아닌 것
  - 포함: 재료 그 자체(`피스타치오`, `세척탈각피스타치오`, `구운가염피스타치오`), 용도에 원료·제과·제빵·업소용,
    이름에 페이스트·분태·분말·스프레드·컴파운드·코팅 등 형태어
  - 브랜드명만 붙은 원물(`세튼 피스타치오`)처럼 놓치는 경우가 있음
- 검색어당 기본 최대 5,000건 조회. 전체 건수보다 적게 조회하면 요약에 `※ 전체 N건 중 M건만 조회함` 표시.
- `--suppliers N`은 핵심 재료 상위 N개를 자동 조회합니다(`INGREDIENT_SEARCH_TERMS`).
  - 검색어 변환: `면류(카다이프 추정)` → `카다이프`, `카카오` → `카카오분말`+`코코아분말`
    (`카카오`만 쓰면 색소·그래놀라·음료가 섞임)
  - 건너뜀: 설탕·소금·물엿·식물성 기름·견과류·밀가루·계란·초콜릿(너무 흔해 소스·향료 결과로 넘침),
    버터·분유(축산물이라 이 데이터에 거의 없음), 마가린
  - 두쫀쿠 기준으로는 카카오 → 카다이프 → 피스타치오가 자동 조회됨
- 향료·착색료·혼합제제·복합조미식품 유형은 재료용에서 제외합니다.
- 결과는 `data/foodsafety/ingredient-*.json`에 캐시됩니다.
- **가격·온라인 판매처는 공공데이터에 없습니다.** 다음 단계에서 네이버 쇼핑 검색 API로 보강 예정.

## 원재료 정리 규칙

- 괄호 내용 제거: `콩기름(대두유)` → `콩기름` (괄호 안 쉼표로 쪼개지 않음)
- 제외: 정제수, 식품첨가물, 과자류, 캔디류, 곡류가공품 등 묶음 표기와 화학명 첨가물(`D-소르비톨`, `~나트륨`, `~산`)
- 동의어 통합: 중력분·박력분·소맥분 → 밀가루, 코코아·카카오 → 카카오, 화이트컴파운드·초콜릿 → 초콜릿, 가공버터 → 버터, 채종유·대두유·해바라기유 등 → 식물성 기름, 땅콩 또는 견과류가공품 → 견과류, 건면·숙면·면류 → 면류(카다이프 추정) 등
- 식품유형 묶음 표기(당류가공품, 과자, 기타농산가공품, 식용유지류 등)는 재료가 아니므로 제외
  (`INGREDIENT_SYNONYMS`, `INGREDIENT_STOPWORDS`에서 수정)

## 한계

- 이름 **포함** 검색이라 다른 음식이 섞일 수 있습니다(`derived`로 표시만 하고 제외하지 않음).
- 허가(신고)일은 실제 출시일과 다를 수 있습니다.
- 품목제조보고 대상 제품만 나옵니다. 매장에서 직접 만들어 파는 메뉴(즉석판매)는 대부분 포함되지 않습니다.
